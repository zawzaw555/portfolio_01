# My Portfolio Webside

## 概要
HTML / CSS / JavaScript で作成した自己紹介用ポートフォリオサイトです。
ポロフィール、スキル、制作物一覧、連絡先を1ページで確認できる構成にしています。

## 使用技術
- HTML
- CSS
- JavaScript
- Font Awesome
- Google Fonts

## 主な
- レスポンシブ対応
- ハンバーガーメニュー
- スキル一覧の表示
- 制作物へのリンク
- 履歴書PDFのダウンロード

## 工夫した点
- 1ページで自己紹介から制作物まで見られる構成にした
- CSS Grid / Flexbox を使ってレイアウトを作成した
- JavaScriptでサイドメニューの開閉を実装した
- 色やフォントを統一して、見やすいデザインを意識した

## 今後改善したい点
- お問い合わせフォームを実際に送信できるようにする
- アニメーションやアクセシビリティを改善する
- 制作物の詳細ページを追加する
